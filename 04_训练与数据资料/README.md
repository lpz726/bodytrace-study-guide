# 训练与数据构造资料

| 资源 | 学习重点 |
| --- | --- |
| [MoGe 官方训练教程](https://github.com/microsoft/MoGe/blob/main/docs/train.md) | 数据格式、v1/v2 微调、v3 细化训练和配置。 |
| [Sapiens2 法线训练教程](https://github.com/facebookresearch/sapiens2/blob/main/docs/train/NORMAL.md) | 单位向量法线标签、数据类、配置与启动脚本。 |
| [Sapiens2 Pointmap 训练教程](https://github.com/facebookresearch/sapiens2/blob/main/docs/train/POINTMAP.md) | 相机系逐像素三维点标签，可由深度和内参或网格渲染构造。 |
| [Omnidata 数据构造流程](https://github.com/EPFL-VILAB/omnidata) | 从三维扫描生成 RGB、深度、法线和相机等监督；各组成数据许可需分别核对。 |
| [THuman 数据说明](https://github.com/ytrock/THuman2.0-Dataset) | 人体纹理扫描与数据组织。主要是着衣表面；当前协议限非商业研究，产品训练需另行解决许可和皮肤真值来源。 |
