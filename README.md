# BodyTrace 算法与模型训练学习资料

围绕八视图自由人体曲面重建整理的中文学习索引，涵盖人体模型构造、法线和深度预测训练、多视图匹配，以及联合曲面优化。

原资料整理日期：2026 年 10 月 19 日。GitHub 归档日期：2026 年 11 月 2 日。

## 开始阅读

1. 点击 GitHub 页面上方 **Code → Download ZIP**，下载后解压。
2. 双击 `index.html` 或 `00_开始阅读.html`，即可在浏览器查看完整索引。
3. 支持离线搜索、优先级筛选和逐篇标注；访问论文、课程与官方代码需要联网。

GitHub 仓库文件页展示 HTML 源码；下载后本地打开即可阅读。仓库保留静态站点入口 `index.html`，未自动开启 GitHub Pages。

## 资料内容

| 目录 | 内容 |
| --- | --- |
| `01_基础材料` | 计算机视觉、多视图几何与 PyTorch3D 教程 |
| `02_核心论文` | 12 个核心学习条目，包括 14 篇独立论文 |

每个论文条目标注学习优先级、输入输出、训练方式、模板依赖、与 BodyTrace 的关系、适用边界和复现状态。

## 建议学习顺序

DeepSDF / PIFu → DSINE / Sapiens2 → MVSNet / DiffuStereo → NeuS / MonoSDF → SparseNeuS。

跨数据模型训练、单对象优化和几何后处理在资料中分别标注。链接核验、训练流程可用和已经复现是不同状态；本资料包不声称完成这些方法的训练复现。

## 来源与使用

论文、模型和数据均指向作者或官方资源。中文导读和学习建议不替代原文；资料按原整理日期保留，未在归档时重新核验所有外部资源。

本仓库不包含完整论文 PDF、模型权重、训练数据或真人照片。第三方论文、代码、权重和数据的权利及许可归原作者或权利人所有，使用时分别查看原资源许可；THuman 的资料中保留了非商业研究用途限制说明。

`source-files.sha256.json` 记录来自原学习资料文件夹的文件身份；`06_文献索引/文件SHA256.txt` 为本次归档重新生成的文件校验清单。
