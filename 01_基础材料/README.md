# 基础课程与教材

| 资源 | 学习重点 |
| --- | --- |
| [斯坦福 CS231n](https://cs231n.stanford.edu/schedule) | 反向传播、CNN、Transformer、优化和迁移学习。 |
| [Szeliski Computer Vision 第二版](https://szeliski.org/Book/) | 成像、模型拟合、深度估计与三维重建；作者官网提供电子版入口。 |
| [Multiple View Geometry 第二版](https://www.robots.ox.ac.uk/~vgg/hzbook/) | 相机、极线几何、三角化、重投影误差与 bundle adjustment。 |
| [PyTorch3D 教程目录](https://pytorch3d.org/tutorials/) | 可微渲染、网格和三维损失。 |
| [PyTorch3D 网格变形实践](https://pytorch3d.org/tutorials/deform_source_mesh_to_target_mesh) | Chamfer、边长、法线一致性与 Laplacian 正则。 |
| [PyTorch3D 照片监督网格实践](https://pytorch3d.org/tutorials/fit_textured_mesh) | 轮廓、RGB 与可微网格优化。 |
