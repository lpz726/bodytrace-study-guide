使用与标注

按“表示 → 人体网络 → 几何观测 → 跨图证据 → 联合优化”的顺序学习。优先级 A 表示当前重点，B 表示后续能力，C 表示按需选读；优先级与实践任务是针对本项目的学习建议。

跨数据训练用于学习可泛化模型；单对象优化用于拟合一次采集；法线积分与深度融合还可能是纯几何求解。三者在每篇标注中分别说明。

当前主路径使用 MoGe-2 与一代 Sapiens 提供观测。Sapiens2、MoGe-3 及其他候选不代表已经接入项目。法线一致性、网格密度、位移量和渲染观感都不能代替独立三维误差。

资源链接在整理所依据的检索中已核验，不代表完整训练代码可用、已经复现，或已在本项目证明精度收益。具体限制保留在对应条目。

建议学习路线

DeepSDF / PIFu → DSINE / Sapiens2 → MVSNet / DiffuStereo → NeuS / MonoSDF → SparseNeuS

  1. 构造人体模型：跑通渲染、查询点采样、训练与网格导出。
  2. 微调人体法线：固定数据划分，比较基础权重和微调结果。
  3. 验证跨视图深度：先固定身体和相机，再单独增加角度及姿态困难。
  4. 联合曲面优化：比较 RGB、深度、法线各自与联合的几何收益。
